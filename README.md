# Adobe Photoshop 2023 破解版

本软件适用于 ***Windows 10以上版本，x64架构*** 的设备。其他类型设备上可能无法运行。

本破解版安装包仅供交流学习，禁止分享到任何平台，下载后请24小时内及时删除，有能力者请至Adobe官网支持正版！！！

**官网链接：<https://www.adobe.com/cn/>**

## 破解版原理

Photoshop现在已经实行订阅制，安装破解版后其与Adobe服务器连接，就需要付费订阅正版，否则无法使用。本破解版通过断网（阻止Photoshop出站）来使其可以长期白嫖。

## 破解版安装方法

从**发行版**解压文件包，**先阅读说明**，然后切断网络连接，管理员权限运行**Set-up.exe**。

安装程序窗口，安装位置一定要自己选一个目录，不要使用默认！

接下来就正常等待其安装完毕。

安装好后先不要恢复联网，用管理员PowerShell运行一段代码（本仓库和安装说明都有），来阻止Photoshop联网。运行完毕后才可以恢复网络连接并启动软件，接下来就可以正常使用了。
